# failed-login-monitor
A Bash-based security monitoring script developed on Ubuntu Server to identify and analyze failed SSH login attempts.

Features
- Detects failed SSH authentication attempts.
- Identifies targeted usernames and source IP addresses.
- Analyzes login activity within a 24-hour window.
- Assigns severity levels.
- Generates timestamped security reports.

Technologies
- Ubuntu Server
- Bash
- Linux authentication logs
- SSH

Skills Demonstrated
- Linux administration
- Security log analysis
- Threat detection
